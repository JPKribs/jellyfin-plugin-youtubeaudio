A Jellyfin plugin to download audio tracks from YouTube URLs or playlists. Once downloaded, files are tagged using internal metadata and imported into a local Jellyfin music library.

<br clear="left">

## Documentation

Installation, setup, downloading, importing, and approved user downloads are covered in the **[YouTube Audio documentation](https://jpkribs.github.io/jellyfin-plugin-youtubeaudio/)**.

Plugin repository URL for Jellyfin:

```
https://raw.githubusercontent.com/JPKribs/jellyfin-plugin-youtubeaudio/master/manifest.json
```
