A read-only view of the queue that any signed-in user can open to see what is waiting to be added and where it stands.
Provide a YouTube video or playlist URL to queue the audio for download.

Import a Playlist

Queue every track from a playlist exported from another music service. Each track is matched to a YouTube upload when it downloads, and keeps the service's title, artist, album and track details as its tags.
Each imported playlist becomes a private Jellyfin playlist with the same name, owned by this user, filled as its songs reach the library. If the user already has a playlist with that name, missing songs are added to it.
