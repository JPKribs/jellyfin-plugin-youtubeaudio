Queue songs to download as audio, then tag and import them from the Import tab.
A YouTube video or playlist link. Each video is queued to download as audio.
In the Music app, choose File → Library → Export Library… to pick from all your playlists, or export one playlist as XML or text.
Export your playlists with Exportify: one playlist as a CSV file, or all of them as a ZIP. Liked Songs is offered like a whole library and does not become a playlist.
Each track is matched to a YouTube upload when it downloads, and keeps the export's title, artist, album and track details as its tags.
Each imported playlist becomes a private Jellyfin playlist with the same name, owned by this user, filled as its songs reach the library. If the user already has a playlist with that name, missing songs are added to it.
