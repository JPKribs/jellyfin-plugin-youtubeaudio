Troubleshooting

yt-dlp and the Deno runtime it needs for YouTube are downloaded into the plugin folder automatically, and yt-dlp is kept up to date (checked every 12 hours). Only set a path below to use your own yt-dlp instead.
Absolute path to the yt-dlp binary (e.g. /opt/homebrew/bin/yt-dlp).
