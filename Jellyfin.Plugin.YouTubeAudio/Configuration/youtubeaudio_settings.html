    Troubleshooting

    yt-dlp and the Deno runtime it needs for YouTube are downloaded into the plugin folder automatically and kept up to date (checked every 12 hours). Every download is checked against the checksum its release publishes before it is used. Only set a path below to use your own yt-dlp instead.
    Absolute path to the yt-dlp binary (e.g. /opt/homebrew/bin/yt-dlp).
    YouTube changes frequently and old yt-dlp versions stop working. To update yt-dlp and Deno right away instead of waiting for the next check, use this button. It waits for running downloads; cancel them on the Download tab to update now.
    These actions are destructive and cannot be undone.
    Reset Queue
    Stop running downloads and clear the download queue. Queued, in-progress and downloaded items are removed, along with their cached files.
    Reset Cache
    Stop running downloads, delete every file in the download cache and clear the download queue. This removes all downloaded files that have not been imported.
