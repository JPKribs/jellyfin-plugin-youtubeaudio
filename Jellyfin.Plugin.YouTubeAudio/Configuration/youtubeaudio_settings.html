Troubleshooting

The plugin downloads yt-dlp and the Deno runtime it needs, checks each against its published checksum, and updates them every 12 hours.

Update Now

Updates yt-dlp and Deno without waiting for the next check. It waits for running downloads, so cancel them on the Download tab to update now.
Both stop running downloads first and cannot be undone.
